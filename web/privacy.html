פרטיות

עודכן לאחרונה ב-4 בנובמבר 2026

שרטוטי היא לוח סקיצות עם מידות, בדפדפן, באפליקציית Android ובתוכנה למחשב. אין בה חשבונות משלה ואין שרת או מסד נתונים שמחזיקים את הסקיצות, ולכן מי שמפעיל את שרטוטי לא יכול לקרוא אותן.

מה נשאר במכשיר שלכם

הפרויקטים, הסקיצות, המסמכים וההגדרות נשמרים באחסון של הדפדפן הזה (או של האפליקציה). שום דבר לא יוצא מהמכשיר אלא אם מתחברים ל-Google Drive.

אופציונלי: סנכרון עם Google Drive שלכם

אם בוחרים התחברות עם Google, נכנסים עם Google ו-שרטוטי שומרת את הנתונים בתיקיית אפליקציה מוסתרת ב-Google Drive שלכם. היא מבקשת גישה רק לתיקייה הזו (ההרשאה drive.appdata), וגם שם וכתובת מייל כדי להראות מי מחובר. היא לא יכולה לראות, לרשום או לשנות שום קובץ אחר ב-Drive, והתיקייה המוסתרת גלויה רק לכם ולאפליקציה. אסימון הכניסה והמייל נשמרים במכשיר שלכם.

השימוש של שרטוטי במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use. הנתונים מ-Drive משמשים רק לסנכרון בין המכשירים שלכם.

האתר

האתר הוא קבצים סטטיים ב-GitHub Pages. כמו כל שירות אחסון, GitHub עשויה לשמור יומני בקשות רגילים (כמו כתובת IP). הגופן נטען מ-Google Fonts, ומסך ההורדות בודק ב-GitHub מהי הגרסה האחרונה, ולכן השירותים האלה רואים את כתובת ה-IP שלכם כשהם נטענים. שרטוטי עצמה לא משתמשת באנליטיקס, בפרסום או בעוגיות מעקב.

מחיקת הנתונים

  • בחלון חשבון Google, בחרו מחיקת כל הנתונים שלי מ-Drive. זה מוחק את הקבצים של שרטוטי מה-Drive, מבטל את הגישה של האפליקציה ומוחק את העותק שבמכשיר הזה. מכשירים אחרים שעדיין מחוברים יעלו את העותק שלהם שוב, אז נתקו אותם קודם.
  • אפשר גם להסיר את הגישה של שרטוטי ואת הנתונים המוסתרים שלה בעצמכם בחשבון Google, תחת אבטחה ← החיבורים שלך לאפליקציות ושירותים של צד שלישי.
  • ניקוי נתוני האתר בדפדפן, או הסרת האפליקציה, מוחקים את העותק שבמכשיר.
